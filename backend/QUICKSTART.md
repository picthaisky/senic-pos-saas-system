# Quick Start

- Run only the web app, without a backend: [frontend/README.md](../frontend/README.md)
- Run the backend locally and sign in with the demo users: [README.md](README.md)
- Run everything with Docker Compose: `docker-compose up --build` in this folder, then open
  `http://localhost:8080` (details in [DEPLOYMENT.md](DEPLOYMENT.md))
- Deploy with GitHub Actions and Portainer: [deploy/README.md](../deploy/README.md)
