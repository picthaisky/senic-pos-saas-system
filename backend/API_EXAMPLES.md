# API Examples

Requests, responses, roles and status codes of every endpoint are in
[docs/API_REFERENCE.md](../docs/API_REFERENCE.md), which is the contract between the frontend and
the backend. Sign-in and a few sample requests are in [README.md](README.md).

When the API runs in Development, Swagger UI at `/swagger` lets you try the endpoints: call
`POST /api/auth/login`, then paste the `accessToken` into **Authorize**.
